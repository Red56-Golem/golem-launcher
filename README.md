# Golem Launcher

A Windows app that runs several Minecraft instances side by side, each in its own square, through [Prism Launcher](https://prismlauncher.org/).

## Download

Get Golem Launcher from its author, unzip it and run `Golem Launcher.exe`. After that, Golem Launcher updates itself: an **Update** button appears in the app when a new version is out.

You need Prism Launcher installed, with your Minecraft accounts signed in there once.
